# Tel verən və verməyən

## Qurulum
1. `main.py` içində `self.add_user("admin", "admin", True, "*")` sətrində admin şifrəsini dəyişin.
2. Logonu `assets/logo.png` kimi əlavə edin.
3. Bu qovluğu GitHub-a yükləyin (repo-nun kökündə `main.py`, `buildozer.spec`, `trainees.csv` olmalıdır).
4. Actions bölməsində "Build APK" işini işə salın və `app-apk` faylını yükləyin.

## İstifadə
- Admin 12 istifadəçiyə qədər əlavə edə bilər, onlara admin hüququ verə bilər və qrup icazələri seçə bilər.
- Kursant siyahısı qruplar üzrə göstərilir: Bəli / Xeyr seçimi.
- Xeyr seçiləndə səbəb yazılmalıdır.
- "Yadda saxla" yalnız dəyişikliyi tarixçəyə yazır. Tarixçə tarix və saatla saxlanılır.
- Tarixçədə "Word-ə yüklə" düyməsi yalnız Xeyr olanları `xeyr_siyahisi.docx` faylına yazır.
- Admin tarixçədəki qeydə toxunub dəyişiklik edə bilər.
